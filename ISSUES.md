## ✅ ЗАКРЫТЫЕ ПРОБЛЕМЫ

### GUI-001 — Логотип в диалоге обновления (только v5 PyQt)
**Файл был:** `gui/dialogs/dialog_update_splash.py`  
**Описание:** В v5 PyQt-версии в окне обновления отображался SVG-иконка щита вместо логотипа.  
**Решение:** Устаревшая проблема — v6 не использует PyQt6 и нет диалогов обновления.  
**Статус:** ✅ ЗАКРЫТА (архитектура v6 не использует PyQt)

### ACC-001 — Проверка аккаунтов без прокси (только v5 PyQt)
**Файл был:** `gui/screens/screen_accounts.py`  
**Описание:** В v5 при нажатии «Проверить» без прокси — ошибка «Добавьте прокси перед тестом».  
**Решение:** v6 архитектура (Tauri + React + FastAPI) — `/api/accounts/test`, прокси не обязателен.  
**Статус:** ✅ ЗАКРЫТА (архитектура v6)

### PRX-001 — Прокси сбрасываются при перезапуске (только v5 PyQt)
**Файл был:** `gui/screens/screen_accounts.py`  
**Описание:** В v5 глобальные прокси хранились только в памяти (`_SESSION_PROXIES`).  
**Решение:** v6 `core/storage.py` сохраняет прокси на диск в `global_proxies.json`. Поля `proxy`/`proxy_list` при загрузке аккаунтов — сбрасываются (сессионные данные).  
**Статус:** ✅ ЗАКРЫТА (v6 storage.py)

### PRX-002 — Импорт аккаунтов без глобального пула (только v5 PyQt)
**Файл был:** `gui/screens/screen_accounts.py`  
**Описание:** В v5 без прокси — автопроверка не запускалась, неограниченный параллелизм.  
**Решение:** v6 UI (React) — пользователь управляет проверкой через раздел «Аккаунты» вручную или кнопкой «Проверить все».  
**Статус:** ✅ ЗАКРЫТА (архитектура v6)
