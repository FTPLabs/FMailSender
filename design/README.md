# FMail Sender Pro — Design Mockups

  Два варианта нового premium UI, реализованных как React/TSX.

  ## Варианты

  | | Стиль | Путь |
  |---|---|---|
  | **CyberPro** | Киберпанк neon, `#040410` BG, 3 animated orbs + aurora | `mockups/cyberpro/` |
  | **CleanDark** | Premium minimal dark, `#09090F` BG, aurora drift | `mockups/cleandark/` |

  ## Изменения vs старого UI
  - ✅ Реальный логотип SVG (градиент `#7C3AED → #06B6D4`)  
  - ✅ Шрифт **Syne** для заголовков/навигации  
  - ✅ Анимированный двухслойный график (Безье, draw-on-load)  
  - ❌ Строка поиска удалена  
  - ❌ Иконка пользователя удалена  
  - ❌ «Лимит на сегодня» удалён  

  ## Цветовая система
  | Цвет | Hex |
  |---|---|
  | Violet | `#8B5CF6` / `#7C3AED` |
  | Cyan | `#06B6D4` |
  | Green | `#10B981` |
  | Red | `#EF4444` |

  ## Шрифты
  - Заголовки: **Syne** 700–800  
  - UI-текст: **Inter** 400–600  
  - Цифры: **JetBrains Mono** tabular-nums
