# Agent Report Skill — Стандарт отчёта

## Принцип

Каждый агент при завершении задачи ОБЯЗАН выдать структурированный отчёт.
Отчёт — КРАТКИЙ (экономим токены, см. token-economy).
Формат стандартизирован — не изобретай новый.

## Формат отчёта одного агента

```
### [AGENT_NAME] — [TASK_SHORT_DESCRIPTION]
Статус: ✅ OK | ⚠️ WARN | ❌ ERROR | ⏭️ SKIP (не применимо)
Изменено: N файлов
Проверок пройдено: X/Y

Изменения:
• [file.py:line] — [что сделано, 1 строка]
• [file2.py] — [что сделано, 1 строка]

Предупреждения: [если есть] | Нет
Блокеры: [если есть] | Нет
```

## Финальный сводный отчёт (Orchestrator или Main Agent)

```
## ✅ Задача выполнена: [НАЗВАНИЕ]
Версия: [если изменилась] | Без изменений
Время: [приблизительно]

| Агент | Задача | Статус | Файлов |
|-------|--------|--------|--------|
| Security Agent | проверка секретов | ✅ OK | 0 |
| Code Reviewer | code review | ✅ OK | 0 |
| GUI Agent | исправление отступов | ✅ OK | 2 |
| Cleanup Agent | удаление кэша | ✅ OK | 15 |
| DevOps | обновление версии | ✅ OK | 2 |

Итого изменений: N файлов
Блокеров: 0
Релиз: [ГОТОВ / ТРЕБУЕТ ДОРАБОТКИ]
```

## Примеры хороших отчётов

### Пример 1: GUI Agent
```
### GUI Agent — исправление координат экрана аккаунтов
Статус: ✅ OK
Изменено: 1 файл
Проверок пройдено: 8/8

Изменения:
• gui/screens/screen_accounts.py:45 — setGeometry→QVBoxLayout
• gui/screens/screen_accounts.py:67 — хардкод 10px→Spacing.MD

Предупреждения: Нет
Блокеры: Нет
```

### Пример 2: Cleanup Agent
```
### Cleanup Agent — очистка репозитория
Статус: ✅ OK
Удалено: 47 файлов (кэш, .pyc)

Удалено:
• __pycache__/ (23 файла)
• *.pyc (21 файл)
• dist/ (3 файла) 

Предупреждения: found 2 unused imports (F401) — не критично
Блокеры: Нет
```

## Когда статус ❌ ERROR

Блокер должен быть конкретным:
```
### Security Agent — проверка секретов
Статус: ❌ ERROR
Блокеры:
• CRITICAL: core/sender.py:145 — захардкоженный API ключ "sk-..."
  → РЕЛИЗ ЗАПРЕЩЁН до исправления
```

## При skip (⏭️)

```
### Proxy Expert — проверка прокси
Статус: ⏭️ SKIP
Причина: задача не затрагивала прокси-логику
```
