  # Color Palette Skill — FMailSender v3.6.2

  > Единственный источник правды для цветов. Менять цвета только в `shared.tsx` (объект `C`).  
  > Визуальный файл: `design/color-palette.svg`

  ---

  ## Фоны

  | Токен    | Hex        | Использование                        |
  |----------|------------|--------------------------------------|
  | bg       | `#07090f`| Основной фон всего приложения        |
  | surface  | `#0d1117`| Карточки, сайдбар, хедер, модалки    |
  | surface2 | `#12171f`| Вложенные поверхности, тулбары       |

  ## Акцентные (фиолетовый)

  | Токен        | Hex / Value               | Использование                          |
  |--------------|---------------------------|----------------------------------------|
  | purple       | `#8b5cf6`               | Основной акцент, кнопки, активный nav  |
  | purpleDark   | `#7c3aed`               | Hover, начало градиента                |
  | purpleLight  | `#a78bfa`               | Конец градиента, светлые акценты       |
  | purpleDim    | `rgba(139,92,246,0.12)` | Фон активного nav-элемента             |
  | borderAccent | `rgba(139,92,246,0.35)` | Граница активных блоков                |

  ## Семантические

  | Токен | Hex        | Dim-фон (badge)              | Использование           |
  |-------|------------|-------------------------------|-------------------------|
  | green | `#22c55e`| `rgba(34,197,94,0.10)`      | Успех, online, валидный |
  | red   | `#ef4444`| `rgba(239,68,68,0.10)`      | Ошибка, danger          |
  | amber | `#f59e0b`| `rgba(245,158,11,0.10)`     | Предупреждение, bounce  |
  | blue  | `#3b82f6`| `rgba(59,130,246,0.10)`     | Инфо, SSL/TLS           |

  ## Текст

  | Токен      | Значение                   | Использование                    |
  |------------|----------------------------|----------------------------------|
  | text       | `#e2e8f0`                | Основной текст                   |

  | textFaint  | `rgba(255,255,255,0.15)` | Третичный, подсказки, disabled   |

  | Токен  | Значение                   | Использование                    |

  | faint  | `rgba(255,255,255,0.06)` | Фон inactive, hover              |

  ```css

  ```

  ---

  ## Правила применения

  1. **Никогда не хардкодить** цвета в компонентах — только через `C.tokenName`
  2. **Изменять только в `shared.tsx`** (объект `C`) — единственный источник правды
  3. **Тёмная тема единственная** — светлой темы нет и не планируется
  4. **"Спокойный" ≠ серый** — используй мягкие оттенки palette, не белый на сером
  5. **Фиолетовый — первичный акцент** (#8b5cf6) для всех интерактивных элементов
