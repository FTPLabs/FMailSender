  # Inbox Bypass Prompts — Попасть во Входящие

  ## Универсальный промпт (встроен в core/html_generator.py как UNIVERSAL_PROMPT)

  ```
  Ты опытный email-маркетолог с 10-летним опытом. Создай письмо, которое:

  ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:
  - Баланс текст/изображения: минимум 60% текста
  - Максимум 3 ссылки в письме
  - Обязательно: ссылка отписки в footer
  - Не использовать URL-shortener (bit.ly и т.д.)
  - Инлайн CSS, table-based layout
  - Alt-тексты у всех изображений

  КОНТЕНТНЫЕ ТРЕБОВАНИЯ:
  - Не использовать слова: бесплатно, срочно, скидка, акция, гарантия, деньги
  - Персональное обращение по имени в первой строке
  - Конкретная польза в первых 50 символах Subject
  - Subject: вопрос или неожиданное утверждение (вовлечение)
  - Тон: разговорный, от человека, не от компании
  - Одно чёткое действие (CTA) — не несколько

  СТРУКТУРА:
  1. Личное обращение (2-3 предложения)
  2. Конкретная проблема/ситуация (1 абзац)
  3. Решение/предложение (1-2 абзаца)
  4. Один CTA
  5. Подпись с именем (не "Команда компании")

  Содержание: {user_prompt}
  ```

  ## Промпты по варианту использования

  ### Вариант A: B2B / деловое письмо
  ```
  Subject: вопрос о {topic} для {company_name}
  Тон: профессиональный, уважительный, конкретный
  Избегать: общих фраз, корпоративного новояза
  Начинать с конкретного факта или вопроса
  ```

  ### Вариант B: B2C / личное
  ```
  Subject: {first_name}, видел твой вопрос о {topic}
  Тон: дружеский, как от знакомого
  Короткие абзацы (2-3 предложения)
  Эмодзи в subject (1-2 максимум)
  ```

  ### Вариант C: Re-engagement (реактивация)
  ```
  Subject: Всё ок, {first_name}?
  Тон: обеспокоенный, личный
  Не упоминать продукт в первом абзаце
  Открытый вопрос в конце
  ```

  ### Вариант D: Транзакционное (высокая доставляемость)
  ```
  Subject: Ваш {action} подтверждён
  Минимум маркетингового текста
  Только нужная информация
  Plain text версия обязательна
  ```
